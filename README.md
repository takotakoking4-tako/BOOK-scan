# BookScan Web — 試作版

GitHub Pagesで動作する、iPhone Safari向けの連続撮影・PDF作成PWAです。

## 公開手順
1. GitHubで公開リポジトリ `bookscan` を作成。
2. このフォルダ内のファイルをリポジトリのルートにアップロード。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. `https://<ユーザー名>.github.io/bookscan/` をiPhoneのSafariで開く。
5. カメラアクセスを許可。必要なら共有 → ホーム画面に追加。

## 現時点の実装範囲
- ライブカメラ、手動撮影、簡易的な輪郭/静止判定による自動撮影
- 単ページ・見開きの中央2分割、簡易矩形トリミング、明るさ補正
- IndexedDBへのページ保存、削除・並び替え
- 複数ページのPDF生成と共有/ダウンロード

## 重要な制約
- **台形補正、曲面補正、ページめくりの確実な検出は未実装**。緑枠は簡易エッジ検出による矩形で、ページ輪郭を正確に追跡するものではありません。
- 自動撮影は照明・背景・手の動きに影響されます。初回は「手動のみ」で確認してください。
- 見開き分割は画像の中央で分割するため、実際の綴じ目と一致しない場合があります。
- PDF用jsPDFをCDNから取得するため、初回利用にはインターネット接続が必要です。外部CDNに画像をアップロードする処理はありません。
- 大量ページではiPhoneのメモリ不足によりPDF生成が失敗する場合があります。
- Safariのサイトデータ削除・プライベートブラウズ等で保存ページが消える場合があります。重要な原稿はPDFをこまめに保存してください。
- GitHub Pagesの公開URLは原則として誰でもアクセス可能です。
